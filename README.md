# 🎬 Cinematic Engine — অটো ভিডিও টাইমলাইন স্টুডিও

তোমার রেকর্ড করা **অডিও** দাও → ইঞ্জিন নিজে থেকে **টাইমলাইন, টেক্সট, অ্যানিমেশন, ব্যাকগ্রাউন্ড এফেক্ট** বানিয়ে দেবে →
**রেকর্ড মোড** চালিয়ে Chrome/Windows/Mac দিয়ে স্ক্রিন রেকর্ড করে নাও। প্লেব্যাকের সময় কার্সর লুকানো থাকে,
সব ক্লিক-কীবোর্ড লক হয়ে যায় — ফ্রেমে শুধু ভিডিওটাই দেখা যায়।

সবকিছু **১০০% ব্রাউজারে** চলে। কোনো সার্ভার নেই, কোনো অ্যাকাউন্ট নেই, তোমার অডিও কোথাও আপলোড হয় না।

## ১. চালু করা

এই মুহূর্তে সার্ভার চলছে — উপরের **LIVE PREVIEW** থেকেই খুলে নাও।

পরে নিজের কম্পিউটারে চালাতে চাইলে:

```bash
cd cinematic-engine
python3 -m http.server 8080
# ব্রাউজারে: http://localhost:8080
```

অথবা সরাসরি `index.html` ডাবল-ক্লিক করলেও বেশিরভাগ কাজ করবে
(তবে `http://` দিয়ে খোলটাই ভালো — IndexedDB ও অডিও ডিকোডিং নিশ্চিতভাবে কাজ করে)।

> ⚠️ **বাংলা ফন্ট:** ইঞ্জিন Google Fonts থেকে *Hind Siliguri / Noto Serif Bengali / Baloo Da 2* লোড করে।
> প্রথমবার খোলার সময় ইন্টারনেট থাকলে ফন্টগুলো নেমে ব্রাউজারে ক্যাশ হয়ে যাবে — এরপর অফলাইনেও ঠিকঠাক দেখাবে।

## ২. কাজের ধাপ (মাত্র ৫ ধাপ)

| ধাপ | কী করবে | কোথায় |
|---|---|---|
| **১** | তোমার ভয়েসওভার অডিও টেনে আনো (MP3/WAV/M4A) | বাম পাশে **অডিও** ট্যাব |
| **২** | তুমি যা বলেছ সেই লেখা পেস্ট করো (প্রতি বাক্য আলাদা লাইনে) | **স্ক্রিপ্ট** ট্যাব |
| **৩** | সেনসিটিভিটি/টাইমিং ঠিক করে বড় বাটন চাপো | **জেনারেট** ট্যাব → **টাইমলাইন তৈরি করো** |
| **৪** | টেক্সট/রঙ/অ্যানিমেশন/ছবি পালিশ করো | ডান পাশে **ইন্সপেক্টর** + নিচে **টাইমলাইন** |
| **৫** | স্ক্রিন রেকর্ডার অন করে **রেকর্ড মোড** চাপো | উপরে ডানে লাল বাটন / **F11** |

### স্ক্রিপ্ট দিলে কী হয়?
ইঞ্জিন অডিওর **সাইলেন্স ধরে ভয়েস সিগমেন্ট** বের করে, তারপর তোমার স্ক্রিপ্টের লাইনগুলোকে
সেই সিগমেন্টের সাথে **সময় অনুযায়ী বন্টন** করে (যত দীর্ঘ সিগমেন্ট, তত বড় লাইন)।
ফলে প্রতিটি কথা ঠিক সেই মুহূর্তে স্ক্রিনে আসে যখন তুমি সেটা বলছ।

### স্ক্রিপ্ট না দিলে?
শুধু অডিও থেকে সিন ভাগ হবে। তখন প্রতিটি সিনের টেক্সট খালি/প্লেসহোল্ডার থাকবে —
ইন্সপেক্টরের **“এই সিনে যা দেখাবে”** বক্সে নিজের টেক্সট লিখে দিও।

## ৫. রেকর্ড মোড — ঠিক কী হয়

1. `F11` বা লাল **রেকর্ড মোড** বাটন → নির্দেশনা মডাল খুলবে
2. আগে স্ক্রিন রেকর্ডার **অন** করো:
   - **Windows:** `Win + Alt + R` (Xbox Game Bar, সরাসরি MP4)
   - **Mac:** `⇧ + ⌘ + 5` → Record Entire Screen
   - **OBS Studio** (সবচেয়ে প্রফেশনাল — 1080p60, বিটরেট কন্ট্রোল)
   - **Screenity / Loom** (Chrome এক্সটেনশন)
3. মডালে **৩ সেকেন্ড পরে শুরু করো** চাপো
4. পুরো স্ক্রিন ফুলস্ক্রিন হবে → ৩-২-১ কাউন্টডাউন → ভিডিও শুরু থেকে প্লে
5. এই সময়: কার্সর অদৃশ্য, সব কীবোর্ড/মাউস/স্ক্রল/রাইট-ক্লিক **লক**, শুধু ভিডিও ফ্রেম
6. শেষ হলে `Esc` চাপো → এডিটরে ফিরে আসবে

> কোয়ালিটি অটোমেটিক **উচ্চ**-এ উঠে যায় রেকর্ড মোডে, বের হলে আগের সেটিং ফিরে আসে।

## ৬. প্রফেশনাল ফল পাওয়ার ৭টি নিয়ম

1. **স্ক্রিপ্ট অবশ্যই দিও** — অডিওর সাথে নিখুঁত সিঙ্কের একমাত্র শর্ত
2. অডিও রেকর্ড করো **শান্ত ঘরে**, একটানা; বাক্যের মাঝে ০.৪–০.৬ সেকেন্ড চুপচাপ রাখো
   (ইঞ্জিন সেই চুপচাপ ধরেই সিন ভাগ করে)
3. নরম ভয়েস হলে **সেনসিটিভিটি ৬৫–৮০%**, খুব ডাইনামিক ভয়েস হলে **৩০–৪৫%**
4. রেকর্ডের আগে ডান দিকের কোয়ালিটি **“উচ্চ”** রাখো, বাকি সব ব্রাউজার ট্যাব বন্ধ করো
5. রেকর্ডারের আউটপুট **1920×1080 / 60fps** করো
6. জেনারেটের পর প্রতিটি সিনের টেক্সট একবার চোখ বুলিয়ে নাও —
   অটো ভাগ করা লাইন কখনো ছোট/বড় হতে পারে, `📏 টেক্সট অনুযায়ী সাইজ ঠিক করো` বাটন আছে
7. থিম + এফেক্ট এক রাখলে ভিডিওতে **ব্র্যান্ড কনসিস্টেন্সি** আসে;
   “র‍্যান্ডম এফেক্ট রোল” চেপে গ্যাংটা একবার ঘুরে দেখো

## ৭. ফাইল স্ট্রাকচার

```
cinematic-engine/
├── index.html            সব UI শেল
├── css/
│   ├── app.css           এডিটর UI স্টাইল
│   └── stage.css         ভিডিও ফ্রেমের স্টাইল (1920×1080 ডিজাইন স্পেস)
└── js/
    ├── util.js           গণিত, ইজিং, DOM, স্টোরেজ, বাংলা সংখ্যা
    ├── themes.js         ৬টি থিমের ডিজাইন টোকেন
    ├── audio.js          ডিকোড → লাউডনেস → সাইলেন্স ডিটেকশন → স্ক্রিপ্ট অ্যালাইনমেন্ট
    ├── effects.js        ১২টি canvas ব্যাকগ্রাউন্ড এফেক্ট
    ├── elements.js       ১৫ ধরনের এলিমেন্ট + ১৪টি অ্যানিমেশন রেন্ডারার
    ├── generator.js      অটো টাইমলাইন + ১৮টি সিন টেমপ্লেট
    ├── render.js         DOM স্টেজ রেন্ডারার + অডিও-সিঙ্ক PlaybackEngine
    ├── timeline.js       ভিজ্যুয়াল টাইমলাইন (ড্র্যাগ/ট্রিম/স্ক্রাব)
    ├── inspector.js      প্রপার্টি এডিটর প্যানেল
    ├── record.js         রেকর্ড মোড (ফুলস্ক্রিন + ইনপুট লক)
    └── app.js            সব একসাথে জোড়া + স্টেট + সেভ/লোড
```

**কীভাবে সিঙ্ক নিখুঁত থাকে:** প্লেব্যাক টাইম শুধু `requestAnimationFrame` দিয়ে গুনে না —
প্রতি ফ্রেমে HTML অডিওর `currentTime`-এর সাথে মিলিয়ে **ড্রিফট ০.০৪৫ সেকেন্ডের বেশি হলেই সংশোধন** করা হয়।
সব অ্যানিমেশন CSS keyframe নয়, **সময়ের ফাংশন** হিসেবে হিসাব হয় —
তাই পজ/স্ক্রাব/পিছিয়ে যাওয়া কোনো কিছুতেই অ্যানিমেশন বেসুরো হয় না।

**সেভ:** প্রজেক্ট JSON + ছবি `localStorage`-এ, অডিওর আসল ফাইল `IndexedDB`-তে।
ব্রাউজার বন্ধ করলেও কাজ হারায় না। `সংরক্ষণ` বাটনে `.cineproj.json` ডাউনলোড হয়,
`আমদানি` দিয়ে অন্য কম্পিউটারেও নেওয়া যায় (শুধু অডিওটা আবার আপলোড করতে হবে)।

## ৮. সমস্যা হলে

| সমস্যা | সমাধান |
|---|---|
| অডিও লোড হচ্ছে না | ফাইলটা MP3/WAV/M4A কিনা দেখো; খুব বড় ফাইল (১০০MB+) হলে ছোট করো |
| সিন ভাগ ঠিকমতো হচ্ছে না | সেনসিটিভিটি বদলাও, বা “ন্যূনতম চুপচাপ” কমাও/বাড়াও, তারপর **শুধু সিগমেন্ট দেখো** চেপে মিলিয়ে নাও |
| টেক্সট স্ক্রিনের বাইরে চলে যাচ্ছে | ইন্সপেক্টরে `📏 সাইজ ঠিক করো` চাপো, বা প্রশস্ততা (`w%`) কমাও |
| বাংলা ফন্ট দেখাচ্ছে না | ইন্টারনেট সংযোগ আছে তো? একবার লোড হলে ক্যাশ হয়ে যায় |
| প্লেব্যাক আটকে আটকে চলে | কোয়ালিটি **মাঝারি** বা **নিম্ন** করো (এডিট করার সময়), রেকর্ডের আগে আবার **উচ্চ** |
| রেকর্ডে ফুলস্ক্রিন হলো না | ব্রাউজারকে ফুলস্ক্রিনের অনুমতি দাও; না হলেও ভিডিও ঠিকঠাক চলবে, শুধু ফ্রেম ছোট থাকবে |
